# Multi-Agent AI Infrastructure Stack A production-level autonomous AI system with three agents running 24/7, accessible via Telegram — built to withstand rate limits, auth errors, and model outages without manual intervention. ## Statistics (last 30 days) - 743 million tokens processed - 99.1% uptime - $512 total cost - <250ms average failover time ## 3 Main Agents ### 1. Automation Agent - Model: claude-opus-4 - Function: complete complex multi-step tasks automatically - Capabilities: tool use, web search, code execution, long-context reasoning ### 2. Telegram Assistant - Model: claude-sonnet-4 - Function: personal assistant via Telegram, real-time streaming - Capabilities: session memory, natural language, multi-device ### 3. Reliability Tester - Model: gpt-4o - Function: probe all AI providers every 30 seconds - Capabilities: latency benchmarking, health monitoring, routing signals ## Architecture ## Key Feature: Self-Healing - **Provider failover** — if Anthropic down, immediately switch to OpenAI in <250ms - **Retry with backoff** — temporary failure? Automatic retry before escalation - **API key rotation** — keys are automatically rotated before expiring - **Health probing** — reliability agent continuously monitors all providers - **Auto-restart** — agent crashes? restarts itself without needing to be paged ## Request Flow 1. User sends a message via Telegram 2. Orchestrator selects an agent + provider based on real-time health data 3. Agent processes, calling tools if necessary (multiple rounds possible) 4. Responses are streamed back to the user ## Tech Stack - **LLM Providers**: Anthropic Claude, OpenAI GPT-4o - **Frontend**: Telegram Bot API - **Orchestration**: Custom Python orchestrator - **Monitoring**: Built-in reliability agent + event logging - **Tools**: Web search, code execution, file operations ## How the Tool Works The model does not execute code directly. The flow is: 1. The model emits JSON containing the tool call (e.g., `web_search`) 2. The orchestrator runs the actual tool 3. The result is returned to the model as a new context 4.
